# 检索指标 / Ranking metrics

Recall@k 衡量前 k 个不同文档覆盖了多少相关文档。多个 chunk 命中同一来源不能重复计算 recall。
MRR@k 只看第一个相关文档的倒数排名，没有命中时为零。它不刻画后续多个相关结果的覆盖。
nDCG@k 按排名折扣累积相关性，再除以理想排序的分数。本项目使用二值相关标签，没有声称做 graded relevance 标注。
无答案问题不参与 Recall、MRR 与 nDCG 的平均，单独参与拒答评测；把它们当成 recall 为一会虚增指标。

# 重试与幂等 / Retry and idempotency

临时错误使用有上限的指数退避，并增加 jitter 避免并发客户端同时重试。确定性参数错误不应无条件重试。
HTTP 429 可以在请求预算允许时依据服务端 Retry-After 等信息安排重试；具体服务行为仍需查询对应接口文档。
对扣款或发邮件等有副作用的操作使用 idempotency key。幂等键绑定逻辑操作，同一步重试复用该键，不能每次新建随机键。
重试次数与总时长都应计入预算。日志记录 attempt、error category、delay 和最终状态，便于区分工具故障与规划错误。

# 引用溯源 / Source citations

检索切块保留相对文件名、起止行号和内容摘要生成的稳定 chunk ID。引用形式为 filename.md:L2-L7，必须能回到原文。
文件名与行号相同但内容发生修改时，chunk ID 也会改变。移动文件会改变 ID；这个取舍优先保证可复现性，不保证跨重构的永久标识。
抽取式回答直接展示原文片段和引用，不用语言模型改写。引用存在仅能证明片段来自该文件，不能证明它回答了用户问题。
如果接入生成模型，应额外检查引用 ID 是否在检索候选内，并评估每个事实的证据支持；仅做引用格式校验不足以防止幻觉。

# 时序数据划分 / Temporal split

时序预测按时间先后划分训练、验证和测试，不使用随机打乱后的切分。用未来信息拟合标准化器会造成数据泄漏。
多步预测的标签窗口可能跨越边界，必须按 forecast horizon 清除跨区间样本。仅仅让输入窗口按时间排序还不够。
模型与超参数只用训练和验证集选择，最终 test 留到方案确定后评估。逐时回测必须明确可用历史数据和更新时间。
特征工程也要遵守信息可用性：未来观测到的天气属于未来信息，已发布的天气预报则需要记录发布时间。

# 不确定性 / Conformal intervals

校准区间使用独立 calibration 集的残差分位数，不在最终 test 上选区间宽度。有限样本分位数应处理上取整与样本过少情况。

同时报告 empirical coverage 和 mean interval width，并按预测 horizon 划分；只给平均覆盖率会掩盖远期失效。

# 检索指标 / Ranking metrics

Recall@k 衡量前 k 个不同文档覆盖了多少相关文档。多个 chunk 命中同一来源不能重复计算 recall。
MRR@k 只看第一个相关文档的倒数排名，没有命中时为零。它不刻画后续多个相关结果的覆盖。
nDCG@k 按排名折扣累积相关性，再除以理想排序的分数。本项目使用二值相关标签，没有声称做 graded relevance 标注。
无答案问题不参与 Recall、MRR 与 nDCG 的平均，单独参与拒答评测；把它们当成 recall 为一会虚增指标。

# Markdown 切块 / Ingestion and chunking

输入只读取指定语料目录内的 Markdown 文件，不自动发送到第三方 API。路径按相对根目录记录，外部符号链接不加入语料。
切块按字符预算与原始行边界推进，默认 320 字符，重叠一个行片段。超长单行会切成多个片段，但都保留原始行号。
chunk 太小会丢上下文，太大会稀释检索信号并增加生成时上下文成本。重叠会增加索引体积以及重复候选，应在排序评测时按文档去重。
UTF-8 BOM 与空文件需要正常处理。chunk ID 与语料摘要用于追踪内容变化，而不是用随机 UUID 掩盖版本变化。

# 重试与幂等 / Retry and idempotency

临时错误使用有上限的指数退避，并增加 jitter 避免并发客户端同时重试。确定性参数错误不应无条件重试。
HTTP 429 可以在请求预算允许时依据服务端 Retry-After 等信息安排重试；具体服务行为仍需查询对应接口文档。
对扣款或发邮件等有副作用的操作使用 idempotency key。幂等键绑定逻辑操作，同一步重试复用该键，不能每次新建随机键。
重试次数与总时长都应计入预算。日志记录 attempt、error category、delay 和最终状态，便于区分工具故障与规划错误。
